# 🧠 CA Monk Quiz App

An interactive, timed quiz application built using **React**, **Vite**, and **Tailwind CSS**. Developed for the CA Monk Frontend Internship Assignment.

---

## 🚀 Live Demo

👉 [View the App on GitHub Pages](https://debojyoti2022.github.io/Quiz)

---

## 🛠️ Tech Stack

- ⚛️ React (with JSX)
- ⚡ Vite (for fast development and builds)
- 🎨 Tailwind CSS (utility-first styling)
- 🔀 React Router DOM (for client-side routing)
- 📊 Recharts (for score visualization)
- 💫 Framer Motion (smooth animations)

---

## 📸 Features

- ⏱️ Countdown Timer for Each Question
- 📋 Multiple Question Support
- ✅ Real-time Answer Validation
- 📊 Feedback Screen with Score
- 📈 Graphical Visualization of Result
- 🔁 Option to Retake Quiz
- 🌙 Smooth transitions and UI feedback

---


## Run locally on the machime

⚙️ Installation

**Clone the repository**
   
git clone https://github.com/Debojyoti2022/Quiz.git
cd Quiz

 Install dependencies

npm install

(Run locally)
npm run dev


(Start the JSON Server in this directory 
ca-monk-sentence-tool\src\data)
npx json-server --watch db.json --port 3001

Now you are ready to open the website on machine
